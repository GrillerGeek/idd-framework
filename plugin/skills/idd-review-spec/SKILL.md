# Validate implementation

Run the **review-spec** stage of the bundled [review procedure](references/review.md). Read it and the [Spec contract](references/spec-reference.md) before acting. The main conversation owns selection, orchestration and final project writes; optional reviewers return read-only findings. Use available native tools and the configured model unless a host adapter supplies its own role policy. Selection and safe context capture precede every write.

Produce only the canonical validation report. Preserve the entire Spec and codebase; missing historical evidence and pending human checks remain explicit.
