# Deep Spec review

Run the **deep-review** stage of the bundled [review procedure](references/review.md). Read it and the [Spec contract](references/spec-reference.md) before acting. The main conversation owns selection, orchestration and final project writes; optional reviewers return read-only findings. Use available native tools and the configured model unless a host adapter supplies its own role policy. Selection and safe context capture precede every write.

Invalidate old technical approval with the prescribed operational review sentinel before current reviewer work. Preserve Spec content, lifecycle, gap annotations and human facts; only orchestration publishes current review outputs.
