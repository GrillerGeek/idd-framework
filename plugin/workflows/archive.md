# Archive IDD work

Read the complete [archive procedure](references/archive.md), [manifest contract](references/manifest.md) and [ledger reference](references/ledger.md) before acting. No argument means classify only. Applying requires explicit approval of the concrete committed manifest. The main conversation owns every write, tag and commit; optional workers return read-only evidence. Use actual host capabilities and configured model policy unless a native adapter specifies its role policy.
