# v1.8 interview host evaluation

Date: 2026-11-22 to 2026-11-23. Branch `Grill-retro`. Scenario:
`node scripts/evaluate-pilot.mjs --host <codex|claude> --scenario interview`.
The prompt supplies every answer and authorizes saving, so this observes the
grilling interview with no stakeholder available for follow-up rounds. It does
not observe a live multi-round session with a PM.

Hosts: Codex CLI 0.169.0 (configured model); Claude Code 2.1.330 (claude-opus-5-5).

## Run 1 (before fix)

Both hosts passed the oracle: one new Product YAML plus a same-stem brief with
the generated header, the unrelated Product and dirty user notes preserved, and
lineage `EXPL-cafe` kept. Neither invented glossary terms; uncovered topics
became `needs: stakeholder` open questions.

Findings from reading the saved files and final messages:

- Codex recorded all eleven confirmed answers as decisions ("Name the Product
  Example Desk", "Use Node 22 ESM", ...), duplicating Product fields. Cause: the
  grilling rule "Record every stakeholder decision".
- The brief header claimed "and its live Intentions/Expectations" with none present.
- Claude saved an empty `relates_to: []`.

## Fix

`grilling.md` now records a decision only when it settles something the
Product's fields do not already say, forbids restating fields as decisions, and
omits an empty `relates_to`. The brief header is
`<!-- Generated from <product yaml path> on <YYYY-MM-DD>. ...`. Covered by two
tests in `tests/pm-path-and-retro.test.mjs`.

## Run 2 (after fix)

Both hosts passed. Neither wrote a `decisions` list or an empty `relates_to`.

- Codex: three stakeholder questions (cost and response-time baseline,
  secondary audiences, glossary terms). Header: `<!-- Generated from docs/products/PROD-6c5e.yaml on 2026-11-23. Do not edit; ask for changes and re-render. -->`
- Claude: two stakeholder questions (cost and secondary audience, response
  target) and one `needs: tech-lead` question (persistence and ingestion of
  the unified queue). Header: `<!-- Generated from docs/products/PROD-4936.yaml on 2026-11-23. Do not edit; ask for changes and re-render. -->`

Suite after the fix: `npm run check` passed; `npm test` 541/541.

## Limits

Automated checks verify mutation scope and Product validity only. The findings
above come from the saved artifacts and final messages, not an independent
full-trace review. Evidence was retained in a session scratch directory and is
not committed.
