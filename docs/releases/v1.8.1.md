# IDD v1.8.1 - Marketplace compatibility

Plugin 1.8.1. Framework v1.8.

## What changed

- Moved the two executable helper scripts from the top-level `plugin/bin/`
  directory to `plugin/scripts/` to avoid Claude marketplace's hosted-plugin
  executable warning.
- Updated skill assembly mappings, command permission paths, tests, and
  contributor documentation while preserving helper behavior and bundled
  `scripts/` entry points.
