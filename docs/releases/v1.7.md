## Installation and compatibility

Follow the [installation guide](../installation.md) for built local checkouts.
Choose native installation, the standalone router or selected standalone stages;
avoid duplicate routes within one client. GitHub shorthand and published-ref
installation remain unverified for this migration.

The reviewed standalone installer is pinned at 1.5.25. Single-host installation
copies even without `--copy`; dual-host installation can link Claude into the
project's canonical skills directory. Refresh a local source by repeating the
explicit add command. Host-scoped removal can retain shared canonical copies;
those copies remain installed. Do not broaden deletion to unrelated hosts.

Native local Codex refresh uses a changed version and re-add; its marketplace
upgrade command is Git-only. Claude supports its named local marketplace update.
Codex removes the observed installed caches, while Claude unregisters the plugin
and retains orphaned cached versions. These behaviors were observed with Codex
0.153.4 and Claude Code 2.1.269; they do not certify every future client version.

Contributors and the guarded terminal runner require Node 22.20.0 or newer.
Helpers require Bash, and YAML-using workflows need a safe parser. The Claude
terminal runner requires existing authentication and preserves nested-session
guards. The configured Claude lane is accepted for its measured trace; optional
Sonnet model selection works but its full-procedure lane remains experimental.
Native alias execution, fresh-session desktop discovery, public Forge UI behavior,
real concurrent Exploration writes and later-answer continuation remain unverified.
